One funny line pitching the worst pizza topping ever invented, for the
make.fun competition "The Worst Pizza Topping".

The pitch:

> Introducing soggy-cereal pizza: milk-soaked cornflakes drowning in tomato
> sauce — breakfast and regret in every bite, crunch sold separately.

## How it works

Run `python3 main.py` — it writes the pitch to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
Stdlib only, no network, no third-party packages.
